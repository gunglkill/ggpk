# Расписание ГГПК

Сайт с расписанием Губкинского горно-политехнического колледжа и Android-приложение к нему.
Данные берутся из сообщества ВК «Расписание ГГПК».

## Что здесь есть

| Папка | Что это |
|---|---|
| `build.py` | сборка статического сайта: разбор PDF, страницы групп, преподавателей, JSON с изменениями |
| `schedule_core.py` | парсер PDF-расписания (группы, дни, пары, числитель/знаменатель) |
| `changes/` | файлы изменений, которые заливает ПК |
| `main.pdf` | текущее расписание |
| `.github/workflows/update.yml` | сборка и публикация на GitHub Pages раз в час |
| `app/` | исходники Android-приложения |

## Сайт

https://gunglkill.github.io/ggpk/

- 49 групп, две недели — числитель и знаменатель;
- изменения на конкретные даты;
- 75 преподавателей с поиском;
- таймер до перемены или конца пары;
- тёмная и светлая тема;
- офлайн через service worker.

Обновление: ПК заливает `main.pdf` и файлы изменений, GitHub Actions пересобирает страницы.

## Приложение

APK лежит в разделе [Releases](../../releases).

- WebView-оболочка над сайтом, но с нативным: заставка, настройки, уведомления, офлайн-режим;
- уведомления о начале пары и переменах — те же тексты, что в Telegram-боте;
- три звука уведомлений на выбор;
- фоновая проверка нового расписания;
- предзагрузка всех групп и преподавателей для работы без интернета;
- логотип в шапке показывает состояние сети.

### Сборка APK

Нужны JDK 17, Android SDK с `platforms;android-34` и `build-tools;34.0.0`.
Пути задаются в начале `app/build_apk.ps1`.

```
powershell -ExecutionPolicy Bypass -File app/build_apk.ps1
```

Скрипт делает всё вручную, без Gradle: `aapt2 compile` → `aapt2 link` → `javac` → `d8` → упаковка dex → `zipalign` → `apksigner`.

Ключ подписи в репозиторий не попадает — создаётся локально при первой сборке.

## Структура приложения

```
app/
  AndroidManifest.xml
  build_apk.ps1
  src/ru/ggpk/schedule/
    MainActivity.java      экран с расписанием, офлайн-предзагрузка, статус сети
    SettingsActivity.java  настройки: тема сайта, уведомления, звук, фоновый режим
    Notify.java            расписание звонков, каналы уведомлений, проверка обновлений
    Dialogs.java           окно первого запуска про фоновый режим
    AlarmReceiver.java     приём будильников
    BootReceiver.java      восстановление после перезагрузки
    Prefs.java             настройки приложения
  res/
    values/styles.xml      тёмная тема
    raw/sound1..3.mp3      звуки уведомлений
    mipmap-*/              иконка приложения
    drawable/ic_stat.png   иконка в шторке уведомлений
```
